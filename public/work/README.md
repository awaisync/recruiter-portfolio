# Work photos for the portfolio

Add only photographs, screenshots, or diagrams that you are permitted to publish publicly.

Recommended files:

- `embedded-power-profiling.webp` - Joulescope, X-NUCLEO-LPM01A, or STM32 power-measurement work.
- `embedded-iot-prototype.webp` - an IoT prototype, board, sensor node, or field deployment.
- `diagnostic-systems.webp` - a laboratory instrument or commissioning work, with patient data and customer information removed.
- `software-product.webp` - an app screen or technical dashboard, with private data removed.
- `master-thesis.webp` - a thesis presentation, map, model graphic, or approved research visual.

Use landscape images where possible (roughly 1600 x 1000 pixels). Do not include client data, patient data, passwords, source code containing secrets, or referee contact details.
